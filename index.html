한국어

  1. 수집하는 정보 — 이 확장 프로그램은 개인정보를 수집하지 않습니다. 이름, 이메일, 시트 내용, 탭 이름, 사용 기록 등 어떤 정보도 개발자나 제3자 서버로 전송하지 않습니다.
  2. 저장하는 정보 — 사용자가 만든 폴더 구성(폴더 이름·색·담긴 탭 이름), 고정한 탭 이름, 단축키·표시 설정은 사용자의 크롬 브라우저 안 저장소(chrome.storage.sync)에만 저장됩니다. 이 저장소는 구글이 사용자의 크롬 계정으로 동기화하며, 개발자는 접근할 수 없습니다.
  3. 권한 사용 목적 — storage: 위 2항의 설정 저장 / docs.google.com/spreadsheets 페이지 접근: 시트 하단 탭 줄의 탭 이름을 읽어 패널에 표시하고, 선택한 탭으로 이동.
  4. 외부 통신 — 없습니다. 이 확장 프로그램은 어떤 네트워크 요청도 보내지 않습니다.
  5. 삭제 — 확장 프로그램을 삭제하면 저장된 설정도 함께 삭제됩니다.
  6. 변경 — 이 방침이 바뀌면 이 페이지와 스토어 설명에 반영합니다.
  7. 문의 — hello@ellinote.kr

English

  1. Information we collect — None. This extension does not collect or transmit any personal data: no names, emails, spreadsheet contents, tab names, or usage data are sent to the developer or any third party.
  2. Information stored — Your folder setup (folder names, colors, contained tab names), pinned tab names, and shortcut/display settings are stored only in your browser's Chrome storage (chrome.storage.sync). Google syncs it with your Chrome account; the developer has no access to it.
  3. Permissions — storage: to save the settings above / access to docs.google.com/spreadsheets pages: to read the tab names in the sheet's tab bar, show them in the panel, and switch to the selected tab.
  4. Network — The extension makes no network requests.
  5. Deletion — Uninstalling the extension removes all stored settings.
  6. Changes — Updates to this policy will be posted here and in the store listing.
  7. Contact — hello@ellinote.kr
